# Table of contents

Table of contents helps users navigate notebook/document sections quickly.
The behavior inherits from JupyterLab Table of Contents logic.
All actions are permission-gated.

## What Table of contents is for

Use this feature to:
- view heading structure,
- jump to sections quickly,
- track section hierarchy.

## Open Table of contents

1. Open a notebook/document with headings.
2. Click **Table of contents** in the left activity panel.

If headings are missing, the panel can be empty.

## Navigate by heading

1. Click a heading item in TOC.

Expected behavior:
- Main content scrolls to that section.
- Navigation follows heading order in document.

## Hierarchy behavior

1. Review heading levels in TOC.

Expected behavior:
- Parent/child structure is shown by indentation.
- Nested levels remain readable and consistent.

## Live sync

1. Add/edit/remove headings in the document.
2. Re-check TOC panel.

Expected behavior:
- TOC updates to the latest heading structure.
- Deleted headings disappear.
- New headings appear in correct hierarchy position.

## Empty state

When no supported headings exist:
- TOC shows no items,
- heading navigation is unavailable.

Recommendation:
- use clear heading levels (for example `#`, `##`, `###`).

## Permission notes

Apply this rule to all TOC actions:
- permission granted: panel and navigation are available,
- permission missing: panel is hidden, disabled, or blocked with clear feedback.
