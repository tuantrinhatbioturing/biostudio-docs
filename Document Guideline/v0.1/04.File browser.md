# File browser

File Browser is the central place to browse, upload, organize, and route files for workspace workflows.
All actions are permission-gated.

## What File Browser is for

Use File Browser to:
- navigate workspace storage locations,
- create files and folders,
- upload and monitor file transfer,
- add eligible files to Catalogs,
- add files to Projects.

## Storage structure

File Browser includes 3 storage groups:

### Home

Main workspace folder.
Used for day-to-day working files, including temporary files created during active work.

### Core

Dedicated folder for important and essential workspace files.
Used to separate critical files from regular/temporary workspace files.

### Cloud storage

Shows all cloud storage connections linked to BioStudio.
Users can filter by connection when multiple storages are available.

Includes:
- **Local storage**: shared storage on the main server (shared host by default), managed by administrators. Workspace members can access files stored there.
- **Cloud storage connections**: mounted files from external cloud providers.

Cloud file state:
- downloaded: file is in normal state and available for use,
- not downloaded: file is shown in disabled/low-opacity state until downloaded.

## Open File Browser
![](../images/Pasted%20image%2020260326114259.png)
1. Open the target workspace.
2. Click **File browser** in the left sidebar.
3. Select a source (`Home`, `Core`, or `Cloud storage`).

## Add data files to Catalogs
![](../images/Pasted%20image%2020260326114409.png)
1. In File Browser, locate the target file.
2. Open row **More actions**.
3. Select **Add to Catalogs**.

Expected behavior:
- Only supported data files can be added to Catalogs.
- Unsupported file types do not show the action.
- Added files become available in Catalogs for label-based discovery.

## Track uploading file progress
![](../images/Pasted%20image%2020260326114445.png)
1. Start upload from File Browser.
2. Open/expand the upload progress panel.
3. Monitor item-level progress and status.

Expected behavior:
- Progress is shown per file.
- Users can collapse, close, or clear the upload panel.
- Failed uploads return clear status and allow retry when available.

## Add file to Project
![](../images/Pasted%20image%2020260326114509.png)
1. In File Browser, select one file.
2. Open **Add to project**.
3. In the dialog, choose the target project.
4. Confirm.

Expected behavior:
- Selected files are attached to the chosen project.
- Project picker supports existing project list selection.
- Invalid selection states are blocked with feedback.

## Create file/folder in File Browser

### Create file
![](../images/Pasted%20image%2020260326114557.png)
1. Click **New file** in File Browser actions.
2. Enter file name (and type/extension when required).
3. Confirm creation.

### Create folder
![](../images/Pasted%20image%2020260326114612.png)
1. Click **New folder** in File Browser actions.
2. Enter folder name.
3. Confirm creation.

Expected behavior:
- New item is created in the current folder path.
- Duplicate or invalid names are blocked with clear feedback.

## Permission notes

Apply this rule to all File Browser actions:
- permission granted: action is available,
- permission missing: action is hidden, disabled, or blocked with clear feedback.
