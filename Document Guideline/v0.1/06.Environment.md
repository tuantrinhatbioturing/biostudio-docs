# Environment

Environment manages the runtime used by notebooks and apps.
Behavior follows JupyterLab runtime logic.
All actions are permission-gated.

## Overview

Use Environment to:
- view and switch runtime environments,
- manage packages, variables, and repositories,
- create, edit, or delete environments (with permission).

## Open Environments

1. Open the target workspace.
2. Click **Environments** in the left sidebar.

## UI annotations (from current screen)
![[Pasted image 20260326013233.png]]
1. **Current notebook file**
Shows the notebook currently active in the main panel on the right.

2. **Current running environment**
Shows which environment/kernel is currently attached to the active notebook.

3. **Open in terminal**
Opens a terminal session in the context of the selected environment.

4. **Packages (current environment)**
Lists packages installed in the selected environment.

4.1 **Explore packages (Conda search/install)**
Users can search packages from Conda channels and install them into the current environment.

4.2 **Installed packages**
Shows all packages currently installed in the selected environment.
Users can manage each package (update, view details, uninstall), based on permission.

5. **Environment list**
Shows all global environments declared in Settings and available to the workspace.

6. **Repositories**
Allows users to configure repositories/channels and install packages from those sources.

## Expected behavior

- Notebook, kernel, and environment status stay synchronized.
- Package/variable/repository tabs always reflect the selected environment.
- Switching environment may require kernel restart/reconnect.
- If access is missing, actions are hidden, disabled, or blocked with clear feedback.

## Manage environments

### Create

1. Select target environment.
2. Click **+ Environment**.
3. Enter required fields.
4. Save.

### Edit

1. Select an environment.
2. Update editable fields.
3. Save.

### Delete

1. Select an environment.
2. Click **Delete**.
3. Confirm deletion in the warning dialog.

Deletion behavior:
- This action is destructive.
- If the environment is in use, deletion is blocked with clear feedback.
