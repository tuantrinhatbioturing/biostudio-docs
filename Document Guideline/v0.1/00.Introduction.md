## Overview

**BioStudio** is a collaborative workspace for scientific and data analysis work. It brings together notebooks, files, environments, apps, AI tools, and team collaboration into one platform so users can work in a more organized, reproducible, and controlled way.

In simple terms, BioStudio is a place where individuals and teams can:
- store and organize analysis assets,
- create and run notebook-based workflows,
- manage and discover datasets (from varied Cloud Storage connections, or from Shared data) using a catalog and labeling system,
- configure environments and *allocate compute resources (Shared host (by default), Pod, Cloud machine) — under development...*,
- reuse pre-defined environments and analysis templates from a public library,
- collaborate with teammates,
- and control access through permissions.

![](introduce_20260318171509.png)

BioStudio is designed to support both **personal work** and **team-based work**, which makes it useful for researchers, analysts, and technical teams who need more than just a file storage tool or a notebook editor.

## Why BioStudio matters

Scientific and data analysis work is often fragmented:
- notebooks, files, and environments are separated,
- data is difficult to search and organize,
- compute resources are limited or inflexible,
- and teams spend time setting up environments or repeating similar workflows.

BioStudio addresses these challenges by providing a unified and scalable workspace.

### Key value

![[key_values-20260319015035.png]]

- **Centralized workflow**  
  Keep notebooks, files, environments, and tools in one place.

- **Efficient data discovery**  
  Quickly find datasets using a catalog and labeling system instead of relying on folder structures.

- **Flexible compute scalability**  
  Adapt compute resources to match workload needs—from lightweight tasks to large-scale analysis.

- **Faster onboarding with reusable templates**  
  Start quickly using pre-defined environments and analysis templates that can be cloned into personal workspaces.

- **Reproducibility**  
  Ensure analyses remain stable with controlled environments and configurations.

- **Collaboration with control**  
  Enable teamwork while maintaining clear permission-based access.

### Summary

BioStudio reduces complexity in analysis workflows by combining data organization, compute flexibility, reusable templates, and collaboration into a single, structured platform.

## Core capabilities

BioStudio includes several key capabilities that support end-to-end analysis work.

### 1. Workspace management
BioStudio provides different workspace types so users can work privately or collaborate with a team.

### 2. File operations
Users can upload, download, create, edit, organize, and remove files used for analysis.

### 3. Notebook workflows
Users can create and work with notebooks to explore data, run analyses, and generate outputs.

### 4. Environment management
BioStudio supports environments that help users run notebooks and workflows with the required dependencies and configurations.

### 5. Collaboration
Teams can work together in shared spaces while keeping actions controlled through permissions.

### 6. Permission-based governance
Admins can grant or restrict actions such as editing files, managing environments, configuring resources, or managing group members.

### 7. Apps and advanced tools
BioStudio can include plugins, integrations, and AI-related capabilities that extend the workflow beyond notebooks and files.

## Who BioStudio is for

BioStudio is built for users who need a structured environment to manage technical and scientific work.

### Individual users
People who want a personal workspace for exploration, file organization, and notebook-based analysis.

### Teams and groups
Teams that need to share resources, collaborate safely, and manage access through permissions.

### Admins and workspace managers
Users who need to control who can access resources and what actions each member is allowed to perform.

---

## Example use cases

### Personal analysis
A user uploads files, creates notebooks, and runs experiments in a personal workspace.

### Team collaboration
A group shares notebooks, files, and environments in one workspace and assigns permissions based on each member’s role.

### Governed operations
An admin controls who can upload files, modify notebooks, manage environments, or add and remove users from a group.

---

## Summary

BioStudio is more than a notebook tool or a file manager. It is a structured workspace that helps users and teams:
- organize analysis work,
- collaborate in one place,
- maintain reproducibility,
- and operate with clear permission control.

It is especially valuable when analysis work involves many files, shared resources, multiple users, and environments that need to stay stable and manageable.
