# Catalogs 

All the data files were marked the label, it considers of the catalogs files. Catalogs helps you find and manage workspace data files using labels, source filters, and quick actions.
All actions are permission-gated.

## What Catalogs is for

Use Catalogs to:
- find files quickly by labels and filters,
- narrow results by data source,
- manage catalog items (overview, edit, delete),
- copy file paths for reuse.

A file is treated as a catalog file when it has catalog labels.
Unlabeled files are not included in Catalogs.

## Open Catalogs

1. Open the target workspace.
2. Click **Catalogs** in the left sidebar.

If no catalog data exists, you will see an empty state.
Click **Go to File browser** to add files first.

## Find data

### Search

1. Use the search box at the top of the Catalogs panel.
2. Enter keywords to filter visible catalog rows.

Expected behavior:
- Results update in the current source and filter context.

### Expand/Collapse labels
![[Pasted image 20260326001054.png]]
1. On a row with many labels, click **View more labels**.
2. Click collapse control to reduce label chips.

Expected behavior:
- Expanded state shows all row labels.
- Collapsed state shows summary labels only.

### Full-screen panel
![[Pasted image 20260326001111.png]]
1. Click the panel expand/full-screen control.
2. Browse and filter with a larger catalog area.
3. Click again to return to split view.

## Filter data

### Filter by data source
![[Pasted image 20260326001031.png]]
1. Click the source selector near search.
2. Choose a source (for example `Home (Default), Core`, `Cloud storage`).

Expected behavior:
- Only items from the selected source are displayed.

### Advanced filter
![[Pasted image 20260326001010.png]]
1. Open **Advanced filter**.
2. Add one or more conditions.
3. Set field, operator, and value for each condition.
4. Combine conditions with **AND**/**OR**.
5. Add additional/nested rules when needed.

Expected behavior:
- Results follow the configured filter logic.
- Invalid or incomplete rules are blocked or ignored with feedback.

## Manage a catalog item

Open the row **More** menu to access actions.

### Overview
![[Pasted image 20260326001132.png]]
1. Click **More** on the target row.
2. Select **Overview**.

Expected behavior:
- Detail view opens in read-only mode.

### Edit
![[Pasted image 20260326001150.png]]
1. Click **More** on the target row.
2. Select **Edit**.
3. Update editable fields.
4. Click **Save**.

Expected behavior:
- Changes appear immediately after save.

### Copy path
![[Pasted image 20260325234226.png]]
1. Click **More** on the target row → Select **Copy path**.
2. Or click on the copy path icon at  the catalog item

Expected behavior:
- File path is copied to clipboard.

### Delete
![[Pasted image 20260325235412.png]]
Deleting is destructive.

1. Click **More** on the target row.
2. Select **Delete**.
3. Review warning.
4. Confirm deletion.

Expected behavior:
- Item is removed from Catalogs after confirmation.

## Permission notes

Apply this rule to all Catalog actions:
- permission granted: action is available,
- permission missing: action is hidden, disabled, or blocked with clear feedback.
